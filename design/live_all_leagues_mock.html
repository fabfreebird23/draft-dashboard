What it needsall of it already exists

Nothing new to fetch. Home already loads all four leagues in parallel (weekpulse) and the Live tab already reads ESPN's clock plus Sleeper's uncached points for one league. This is those two, run over the four presets in the same thread pool, plus one join: a map of player → which of your leagues he starts in, which is what powers the exposure counts, the league chips and the red-zone alert. The scoring feed is the same delta diff already kept per league, merged and sorted by time.
